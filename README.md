# 🎸 TuneTutor - Learn Musical Instruments Online 🎶  

TuneTutor is a **MERN-based** e-learning platform that offers courses for various musical instruments. Users can purchase instruments and get access to structured video lessons to learn at their own pace.  

## 🚀 Features  

### 🎵 User Features  
- 🎹 **Buy Instruments** - Purchase a variety of musical instruments.  
- 🎼 **Course Access** - Get free/discounted courses upon purchasing an instrument.  
- 📺 **Video Learning** - Structured video tutorials with progress tracking.  
- 📑 **Certification** - Receive a certificate upon course completion.  
- ❤️ **Wishlist** - Save favorite instruments for later.  
- 🛒 **Cart & Checkout** - Secure payment process for instrument purchases.  

### 🛠 Admin Features  
- 🏪 **Manage Instruments** - Add, edit, and remove musical instruments.  
- 📊 **Sales Analytics** - Track orders and sales performance.  
- 👥 **User Management** - View and manage registered users.  
- 🎬 **Course Management** - Upload and organize video lessons.  

## 🏗️ Tech Stack  

### Frontend (React)  
- ⚛️ React.js  
- 🏗 Redux Toolkit  
- 🎨 Tailwind CSS  
- 🔄 React Router  

### Backend (Node.js & Express)  
- 🚀 Express.js  
- 🔑 JWT Authentication  
- 📧 Nodemailer (Email Notifications)  

### Database (MongoDB)  
- 🗄 MongoDB with Mongoose ORM
